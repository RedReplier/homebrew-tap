# RedReplier Homebrew tap

```bash
brew trust RedReplier/tap
brew install RedReplier/tap/redreplier
```

Installs the standalone `redreplier` binary, with `rr` as a shorter alias. No Node
required. Source and issues live at https://github.com/RedReplier/redreplier-cli.

`npm install -g @redreplier/cli` is the other way in, if you would rather have it as a
Node package.
